# 📂 File Handling and Exception Handling Assignment

This repository contains solutions to a Python assignment focusing on file operations and exception handling. It includes two main scripts:

## 📄 Files Included

### 1. `file_rw.py` - File Read & Write Challenge 🕋️
**Description**:  
This script reads content from an input file (`input.txt`), modifies it by converting all text to uppercase, and writes the modified content to an output file (`output.txt`).

**Usage**:
```bash
python file_rw.py
```

> Make sure to create a file named `input.txt` in the same directory with some sample content.

---

### 2. `error_handling.py` - Error Handling Lab 🧪
**Description**:  
Prompts the user to enter a filename and attempts to read and display its contents. It handles various errors gracefully, including:
- File not found
- Permission denied
- Any unexpected error

**Usage**:
```bash
python error_handling.py
```

> Enter the full filename (e.g., `example.txt`) when prompted.

---

## 🏁 Outcome
By completing this assignment, you've learned:
- How to read from and write to files in Python
- How to handle common file-related exceptions
- How to build robust programs that fail gracefully

1. Clone the repository:

git clone https://github.com/Sir-JamesMuritu/file-handling-assignment.git

2. Run each script with Python:
